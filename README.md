# Nexora

Nexora is a modern electronics and gaming e-commerce frontend designed to showcase popular tech products through a clean, responsive, and user-friendly website.

## 🚀 Features

- Modern electronics and gaming-focused design
- Responsive layout for desktop, tablet, and mobile
- Navigation header with website sections
- Hero section for highlighting the brand
- Featured product cards
- Add-to-cart functionality using JavaScript
- Dynamic cart item count
- Cart alert showing selected products
- Footer section with website information

## 🛍️ Featured Products

The website currently includes sample products such as:

| Product | Price |
|---|---:|

## 🛠️ Technologies Used

- **HTML5** – Creates the structure and content of the website.
- **CSS3** – Handles styling, layout, colors, and responsiveness.
- **JavaScript** – Adds interactivity, including cart functionality.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.

You can also use the **Live Server** extension in Visual Studio Code:

1. Open the project in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🛒 Cart Functionality

When a user clicks an Add to Cart button:

1. The selected product is added to the cart.
2. The cart item count is updated.
3. A message displays the selected cart items.

The cart is currently a frontend demonstration and does not include a backend, payment system, or database.
